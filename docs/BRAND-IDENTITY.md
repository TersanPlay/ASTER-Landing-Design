# ASTER Brand Identity

## Overview

ASTER now adopts a more corporate and professional visual identity centered on a stylized **letter A**. The symbol is intended to communicate structure, reliability, modern software craftsmanship and a premium digital-product aesthetic.

This direction replaces the earlier decorative symbol exploration and becomes the recommended visual signature for project presentation, README headers and documentation touchpoints.

## Brand characteristics

- **Professional** — suitable for design systems, developer tools and product documentation.
- **Technological** — blue tonal range, precise geometry and subtle optical depth.
- **Minimal** — the shape remains simple enough for README usage, docs headers and app-style contexts.
- **Adaptable** — works on dark and light surfaces.

## Usage guidance

### Do
- Prefer the dark icon in the repository README hero.
- Use the light icon on white or pale neutral surfaces.
- Maintain sufficient clear space around the mark.
- Preserve proportions and gradients.

### Do not
- Stretch or rotate the symbol.
- Replace the blue gradient with arbitrary saturated colors.
- Add heavy outlines, glows or game-like visual effects.
- Use the logo over visually noisy backgrounds without a container.

## Color direction

Suggested identity colors:

- Deep navy: `#08111F`
- Midnight surface: `#0B1D36`
- Primary blue: `#255EE5`
- Accent blue: `#7AA8FF`
- Soft text: `#9EB2CC`
- Light background: `#F5F8FD`

## README recommendation

For GitHub presentation, lead with the wordmark or icon in a centered hero section, followed by the product subtitle, badges and key installation links. This creates a more polished first impression than plain emoji- or symbol-led headings.
