# Landing Page Layout Recipes

Plan intent first: audience, value proposition, primary conversion, proof and objections.

## Standard product
Navigation → Hero with primary CTA → outcome proof → key features → product demonstration → benefits → FAQ → final CTA → footer.

## Developer tool
Hero with install action → runnable code example → integration matrix → architecture/technical features → documentation links → CTA.

## Design system
Hero with live preview → foundations → components gallery → theme/material switcher → layouts showcase → installation instructions → documentation index.

## Portfolio
Identity hero → selected work → approach → process → experience/evidence → contact CTA.

## Editorial composition
Use 12-column layouts on wide viewports, 2-column modules for feature contrast, asymmetric imagery only when content remains understandable. Do not repeat the same three-card grid in every section. Use authentic product demonstrations and accessible labels.

## Conversion
Every visible CTA must have a meaningful action, link or honest placeholder. Be careful with fabricated trust metrics; if unavailable, show product features instead.

## Responsive guidance
At 320px preserve meaningful sequence, avoid horizontal scroll. Navigation must collapse predictably, text should wrap, touch targets should be usable. At larger widths maximize clarity, not unused decorative emptiness.
