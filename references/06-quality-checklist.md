# Acceptance and Quality Checklist

## Visual and functional
- [ ] Hero clearly communicates who the product is for and why it matters.
- [ ] CTA works or is openly labelled illustrative.
- [ ] Sections have coherent hierarchy and original composition.
- [ ] Theme and GlassMaterial variants work across surfaces.
- [ ] Mobile at 320/375px has no unwanted overflow.
- [ ] Tablet 768px, laptop 1024px, desktop 1440px are checked.
- [ ] Images have purposeful alt text or are decorative.
- [ ] Forms contain labels, validation messages and semantic controls.
- [ ] Keyboard navigation, focus, escape and modal behavior work.
- [ ] Color contrast and reduced-motion/transparency fallbacks verified.
- [ ] Content is visible with JS disabled wherever practical.
- [ ] No fabricated metrics or misleading endorsements.
- [ ] No dead buttons, broken links or placeholder deployments presented as real.

## Engineering
- [ ] Framework conventions preserved.
- [ ] Semantic variables used instead of repeated magic values.
- [ ] No unnecessary heavyweight dependency.
- [ ] Build, lint and tests executed where tools permit.
- [ ] Evidence and unresolved limitations are described honestly.

## Handoff
List files changed, install/run commands, tokens to customize, completed verification and any untested areas.
